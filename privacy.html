SMART UTILITY DESK

Privacy & data

This page describes the default data behavior of Smart Utility Desk. Review and update it to reflect any backend, analytics, advertising or third-party services you add before publishing.

Local notes

Quick Notes stores note content in your browser's localStorage on this device. Notes are not synchronized to a server by this starter project. Clearing browser data may remove saved notes.

Text and conversion tools

Text analysis, text transformations, unit conversion and timer calculations run locally in your browser. The app does not send this content to a Smart Utility Desk server in this version.

QR generation

QR generation uses the QRCode.js library loaded from a third-party CDN. The entered QR content is processed in the browser by the library. The CDN provider may receive standard network request information when the library loads.

Telegram

When opened inside Telegram, the app loads the Telegram Web Apps SDK. This starter does not transmit Telegram user information to a separate backend. If you add accounts, analytics, remote storage or ads, disclose those practices here and validate Telegram initData on your server before trusting user identity.

Telegram verification and advertising

When launched in Telegram, signed launch data is sent to the backend for signature and expiry validation. The backend uses the Telegram bot token stored in server environment variables and returns a minimal verified user profile. If AdsGram advertising is enabled, the AdsGram SDK may request and display advertising content. Update this notice to match your actual hosting, logs, advertising setup and support contact.
